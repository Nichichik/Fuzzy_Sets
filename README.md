## РАЗДЕЛ 1. ТЕОРЕТИКО-ВЕРОЯТНОСТНАЯ И НЕЧЕТКАЯ БАЗА МОДЕЛИ

### 1.1. Аналитическая модель распределения Хи-квадрат
В качестве исходной базы выступает однопараметрическое распределение $\chi^2(k)$, плотность вероятности которого задается выражением:
$$f_k(x) = \begin{cases} 0, & x \le 0 \\ \frac{1}{2^{k/2} \Gamma\left(\frac{k}{2}\right)} x^{\frac{k}{2} - 1} e^{-\frac{x}{2}}, & x > 0 \end{cases}$$
где:
* $k \in \mathbb{N}, k \ge 2$ — число степеней свободы, определяющее форму, дисперсию и эксцесс кривой;
* $\Gamma(z) = \int_0^\infty t^{z-1} e^{-t} dt$ — гамма-функция Эйлера.

### 1.2. Аналитическое нахождение экстремума (моды)
Для определения вершины функции найдем стационарную точку путем приравнивания первой логарифмической производной к нулю:
$$\frac{d}{dx} \ln f_k(x) = \frac{d}{dx} \left[ \text{const} + \left(\frac{k}{2} - 1\right)\ln x - \frac{x}{2} \right] = \frac{\frac{k}{2} - 1}{x} - \frac{1}{2} = 0$$
$$\frac{k - 2}{2x} = \frac{1}{2} \implies x_{max} = k - 2 \quad (\text{при } k > 2)$$
При $k = 2$: $f_2(x) = \frac{1}{2} e^{-x/2}$. Функция строго монотонно убывает, ее супремум достигается на левой границе: $x_{max} = 0$, а значение равно $f_2(0) = 0.5$.

### 1.3. Проблема нормировки и переход к функции принадлежности $\mu(x)$
В теории вероятностей интеграл плотности равен единице ($\int_0^\infty f_k(x)dx = 1$), из-за чего амплитуда $f_k(x_{max})$ стремительно падает с ростом $k$:
* при $k = 2$: $f_{max} = 0.5$;
* при $k = 6$: $f_{max} \approx 0.135$;
* при $k = 50$: $f_{max} \approx 0.040$.

Согласно аксиоматике Заде, нечеткое число обязано быть нормальным: $\sup_{x} \mu(x) = 1.0$.  
Чтобы сохранить **взаимные пропорции высот между различными величинами** во всем генерируемом множестве и не раздувать каждое число искусственно, введена **глобальная популяционная нормировка**.  
В качестве глобального базиса выбран абсолютный супремум семейства при $k = 2$, равный $f_{global\_max} = 0.5$.

Итоговая функция принадлежности нечеткой величины:
$$\mu_k(x) = \frac{f_k(x)}{0.5} = 2 \cdot f_k(x), \quad \mu_k(x) \in [0.0, \ 1.0]$$

Свойства полученной функции принадлежности:
1. При $k = 2$: вершина касается ровно $\mu(0) = 1.0$ (абсолютная истина в нуле).
2. При $k > 2$: вершины строго лежат в диапазоне $(0, 1)$, сохраняя физический смысл: величины с большим разбросом (большим $k$) обладают меньшей локальной степенью уверенности.

## РАЗДЕЛ 2. ПРЕДСТАВЛЕНИЕ НЕЧЕТКОЙ ВЕЛИЧИНЫ И ВЫДЕЛЕНИЕ ОТРЕЗКА $[A, B]$

### 2.1. Критерий отбора на уровне 0.7 от максимума
Для каждой нечеткой величины с параметром $k$ вычисляется её локальный максимум:
$$\mu_{max}^{(k)} = \mu_k(x_{max})$$
Назначается характеристический уровень уверенности (порог отсечения ядра):
$$y_{cut} = 0.7 \cdot \mu_{max}^{(k)}$$

### 2.2. Нахождение границ характеристического отрезка $[A, B]$
Отрезок $[A, B]$ представляет собой $\alpha$-срез на высоте $y_{cut}$. Точки $A$ и $B$ являются корнями нелинейного уравнения:
$$\mu_k(x) - y_{cut} = 0$$

В программном комплексе реализован метод бисекции (деления отрезка пополам), гарантирующий абсолютную вычислительную устойчивость без деления на ноль:
* **Точка $A$ (левый склон):** ищется на интервале $x \in [0.0001, \ x_{max}]$ (при $k=2$ принимается $A = 0.0$).
* **Точка $B$ (правый склон):** ищется на интервале $x \in [x_{max}, \ x_{max} + 6\sqrt{2k}]$. Верхний предел получен из правила $6\sigma$ математической статистики, где стандартное отклонение Хи-квадрат $\sigma = \sqrt{2k}$.

Характеристики полученного отрезка:
* **Ширина («размытость / число столбиков»):** $W = B - A$.
* **Центр отрезка:** $X_C = \frac{A + B}{2}$.

## РАЗДЕЛ 3. МАТЕМАТИКА ОПЕРАЦИЙ МАНИПУЛИРОВАНИЯ

### 3.1. Арифметика по принципу обобщения Заде ($+$, $-$, $*$, $/$)
Пусть заданы две нечеткие величины $A$ и $B$. Их функции принадлежности имеют пики $\mu_{max}^A$ и $\mu_{max}^B$.  
Согласно принципу Заде, результат операции $C = A \circ B$ существует на уровнях высоты, не превышающих минимальную из двух вершин:
$$y \in [0, \ \min(\mu_{max}^A, \mu_{max}^B)]$$

Формируется эквидистантная сетка из $M = 30$ высот $\{y_m\}_{m=1}^M$. На каждом уровне $y_m$ извлекаются срезы: $A_{y_m} = [a_1, a_2]$, $B_{y_m} = [b_1, b_2]$.  
Применяются правила интервальной арифметики:

1. **Сложение ($A + B$):**
   $$C_{y_m} = [a_1 + b_1, \ a_2 + b_2]$$
2. **Вычитание ($A - B$):**
   $$C_{y_m} = [a_1 - b_2, \ a_2 - b_1]$$
3. **Умножение ($A \cdot B$):**
   $$C_{y_m} = [\min(P), \ \max(P)], \quad P = \{a_1 b_1, \ a_1 b_2, \ a_2 b_1, \ a_2 b_2\}$$
4. **Деление ($A / B$):**
   $$C_{y_m} = [\min(D), \ \max(D)], \quad D = \left\{\frac{a_1}{b_2}, \frac{a_1}{b_1}, \frac{a_2}{b_2}, \frac{a_2}{b_1}\right\}, \quad b_1, b_2 > 0$$

Полученный массив новых интервалов образует замкнутый объемный контур результирующего нечеткого числа.

### 3.2. Теоретико-множественные операции
* **Пересечение (Fuzzy AND / t-норма):**
  $$\mu_{A \cap B}(x) = \min(\mu_A(x), \mu_B(x))$$
* **Объединение (Fuzzy OR / s-норма):**
  $$\mu_{A \cup B}(x) = \max(\mu_A(x), \mu_B(x))$$

### 3.3. Дефаззификация (Center of Gravity — COG)
Приведение нечеткой величины к четкому скаляру осуществляется интегральным методом центра тяжести площади фигуры:
$$X_{COG} = \frac{\int_0^\infty x \cdot \mu(x) \, dx}{\int_0^\infty \mu(x) \, dx} \approx \frac{\sum_{m=1}^M \frac{x_L^{(m)} + x_R^{(m)}}{2} \cdot y_m}{\sum_{m=1}^M y_m}$$

### 3.4. Отношение порядка (Сравнение величин)
Сравнение $A$ и $B$ производится по разности их дефаззифицированных значений:
$$\Delta = X_{COG}(A) - X_{COG}(B)$$
* Если $|\Delta| < 0.1 \implies A \approx B$;
* Если $\Delta \ge 0.1 \implies A > B$;
* Если $\Delta \le -0.1 \implies A < B$.

### 3.5. Метрика расстояния Хаусдорфа
Для оценки близости двух нечетких величин используется метрика Хаусдорфа, вычисленная по их базовым отрезкам уверенности $A = [A_1, B_1]$ и $B = [A_2, B_2]$:
$$d_H(A, B) = \max \Big( |A_1 - A_2|, \ |B_1 - B_2| \Big)$$
*Геометрический смысл:* $d_H$ выражает гарантированную величину деформации (сдвига), необходимую для того, чтобы один отрезок полностью покрыл другой.

## РАЗДЕЛ 4. ГЕНЕРАТОР СОВОКУПНОСТИ НЕЧЕТКИХ ВЕЛИЧИН (ГСНВ)

Генератор моделирует массив случайных нечетких величин мощностью $N \in [100, 300]$:
1. Для каждого объекта псевдослучайно генерируется единственный определяющий параметр — степени свободы:
   $$k_i \sim U_{\mathbb{Z}}(2, 50), \quad i = 1, \dots, N$$
2. Для каждого сгенерированного $k_i$ мгновенно рассчитываются:
   * Координата моды $x_{max} = k_i - 2$;
   * Высота пика $\mu_{max}$;
   * Характеристический срез $[A_i, B_i]$ на уровне $0.7 \cdot \mu_{max}$;
   * Длина отрезка $W_i = B_i - A_i$.
3. Полученная совокупность регистрируется в файле журнала `log.txt` и передается на визуализатор.

## РАЗДЕЛ 5. СЕЛЕКЦИЯ ПОДМНОЖЕСТВ ПО КРИТЕРИЮ

Программа предоставляет аналитический аппарат фильтрации подмножеств по задаваемым числовым диапазонам $[V_{min}, V_{max}]$:
1. **Критерий ширины носителя ($W = B - A$):**  
   Отбираются величины, степень неопределенности которых удовлетворяет условию $V_{min} \le W_i \le V_{max}$. Позволяет отделить компактные (точные) числа от сильно размытых.
2. **Критерий положения вершины ($x_{max} = k - 2$):**  
   Отбираются величины, мода которых локализована в заданном окне базового множества: $V_{min} \le x_{max}^{(i)} \le V_{max}$.

## РАЗДЕЛ 6. КЛАСТЕРНЫЙ АНАЛИЗ (КА МСНВ)

### 6.1. Постановка задачи кластеризации
Разбить сгенерированное множество отрезков $\{[A_i, B_i]\}_{i=1}^N$ на $K$ непересекающихся кластеров $\{S_1, S_2, \dots, S_K\}$ без учителя, минимизируя внутрикластерное расстояние Хаусдорфа.

### 6.2. Модифицированный алгоритм K-Medoids / K-Means
1. **Инициализация:** Случайным образом выбираются $K$ нечетких величин из выборки в качестве начальных центроидов $\{C_1^{(0)}, \dots, C_K^{(0)}\}$.
2. **Шаг распределения (Кластеризация):**  
   Каждая величина $X_i$ относится к кластеру $S_j$, расстояние Хаусдорфа до центроида которого минимально:
   $$X_i \in S_j \iff j = \arg\min_{p \in \{1 \dots K\}} d_H(X_i, C_p)$$
3. **Шаг пересчета центроидов (Поиск медоида):**  
   Внутри каждого сформированного кластера $S_j$ ищется элемент, сумма расстояний от которого до всех остальных членов кластера минимальна:
   $$C_j^{(t+1)} = \arg\min_{Y \in S_j} \sum_{Z \in S_j} d_H(Y, Z)$$
   Такой подход гарантирует, что центроидом всегда остается **реальная нечеткая величина с конкретным целым $k$**, называемая **«Эталонным центроидом»**.
4. **Критерий останова:**  
   Алгоритм завершает работу при стабилизации состава кластеров либо по достижении лимита итераций ($t = 20$).

## РАЗДЕЛ 8. РУКОВОДСТВО ПОЛЬЗОВАТЕЛЯ (ПОРЯДОК РАБОТЫ)

1. **Запуск:** В терминале в рабочей директории выполнить команду:
   ```bash
   python main_gui.py
   ```
   В веб-браузере автоматически откроется страница `http://localhost:8080`.

2. **Работа с вкладкой 1 («Манипулирование величинами»):**
   * Задать параметры $k_A$ и $k_B$ с помощью числовых селекторов;
   * Выбрать интересующую операцию ($+$, $-$, $*$, $/$, Сравнение, Расстояние, AND, OR);
   * Нажать **«Вычислить и отобразить»**;
   * В правой части отобразится координатная плоскость с кривыми исходных величин и объемным телом результата, в левой части — точные численные значения дефаззификации $X_{COG}$ и метрика $d_H$.

3. **Работа с вкладкой 2 («Генератор, Подмножества и Кластеризация»):**
   * В блоке 1 задать объем генерации $N$ (например, 100) и нажать **«Сгенерировать по k»**;
   * В блоке 2 при необходимости выбрать критерий отбора (по ширине $B-A$ или пику $k-2$), ввести диапазон и нажать **«Отобрать подмножество»**;
   * В блоке 3 указать число кластеров $K$ (от 2 до 6) и нажать **«Запустить кластеризацию»**;
   * В правой части отобразится общий график всех 100 величин с раскраской по кластерам, интерактивная таблица [РКА], а ниже — **персональные крупномасштабные графики для каждого кластера** с указанием эталонного центроида $k$, размытости $\Delta X$ и диапазона параметров.
